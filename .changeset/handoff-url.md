`getHandoffUrl(url)`: a link to your website that keeps this player (`mana_handoff=<anonymous ID>.<unix seconds>`), for a browser game on another domain such as the itch.io frame. The handoff parameter is now `mana_handoff` (was `mana_hid`), the same in the Godot, Unity and Unreal SDKs.
